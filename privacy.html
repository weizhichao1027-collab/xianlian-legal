吉他自习室隐私政策

生效日期：2026 年 9 月 8 日

页面更新：2026 年 10 月 28 日

吉他自习室由 Shanghai Qishan Cultural Communication Co., Ltd. 提供。App 不需要注册账号，不包含广告，不会自动把你的练习录音上传到开发者服务器。

版本适用范围：当前上架版本为 1.5 / Build 11。本页按 1.5 的实际功能说明数据处理方式；1.5 沿用 1.3 起的统计同意机制，首次安装时“分享使用统计”默认关闭，主动同意后才初始化统计 SDK。原位更新会沿用已有选择，不会因为升级重新要求已同意的用户开启。1.5 的完整路径为“成长 > 练习设置 > 提醒与数据 > 分享使用统计”，关闭立即生效；练习偏好的“保存 / 取消”不会撤销这个开关的更改。1.5 的屏幕布局、窗口切换与无障碍优化未新增数据采集权限或上传流程。

旧版差异：1.3 的统计开关位于“成长 > 练习设置”。仍使用 1.2 的用户请注意：1.2 已集成友盟并在启动后进行功能统计，不具备上述同意机制；网站更新不会改变已安装的旧版 App。请在 App Store 更新以使用当前的隐私控制。

数据处理摘要

  • 练习检测音频：只在设备本地实时分析，不保存，不上传。
  • 主动演奏留档：最长 180 秒，档案最多保留 24 条，可逐条删除；当前版本支持里程碑保护、用户主动导出及未归档文件恢复。App 不自动上传。
  • 课程进度与设置：保存在 App 本机容器，可随你启用的系统备份迁移；开发者不提供云同步。
  • 使用分析：通过友盟统计 SDK 处理功能事件、随机安装 ID，以及 SDK 自动处理的设备标识和设备/网络信息。首次安装默认关闭，主动同意后才初始化统计 SDK。随机 ID 是假名化标识，不等同于不可识别个人的完全匿名数据。
  • 账号与广告：不需要账号，不包含广告；App 不主动读取 IDFA，不发起 ATT 授权请求。

我们收集的数据

本 App 不自动上传练习录音或音频内容；当前版本的主动导出由你选择接收应用或位置。使用统计中的设备标识和网络信息可能用于区分设备或安装，因此不将其描述为“完全匿名”。

App 不要求你提供姓名、手机号、邮箱、位置、通讯录、照片或社交账号。

我们使用友盟分析功能使用情况和改进产品。当前版本仅在你主动开启“分享使用统计”后初始化 SDK、转发产品事件；麦克风授权不代表统计同意。使用分析包括：

  • 产品交互数据：功能事件名与非个人化参数，例如「开始了某节课程」「完成了某类练习」「切换了某个标签页」。还包含练习开始/结果、主动计时时长、曲目与片段固定编号、作品保存/对比、周目标和系统分享结果；使用随机事件/会话/观察期编号去重，并记录发生时间、时区及版本。上述产品交互数据不包含你的录音、文件路径、音频特征或任何自由输入的文本（包括曲库搜索词）；事件会附带随机安装标识符，因此不将它描述为“未关联标识符”的数据。
  • 随机安装标识符：App 首次启动时在本机随机生成的 ID，用于区分不同安装。该 ID 不与账号、手机号或真实身份关联；系统备份恢复可能恢复该安装 ID，不能保证每次重新安装都会变化。
  • SDK 设备与网络信息：友盟还会自动处理设备标识（如 IDFV/SDK 生成标识）、设备型号、操作系统与应用版本、语言、时区、网络状态及请求 IP 等信息。我们不将其收集范围简化为仅有 App 自定义事件。详细范围见友盟隐私政策。

第三方 SDK

App 集成友盟统计 SDK（UMCommon 7.6.7、UMDevice 3.6.0），由友盟同欣（北京）科技有限公司提供，用于上述产品统计。当前版本在取得统计同意后才初始化 SDK，并在初始化前显式关闭 ASA token 采集、SKAdNetwork 广告归因注册及进端采集。你可在“成长 > 练习设置 > 提醒与数据”关闭“分享使用统计”，修改立即生效；拒绝或关闭不影响核心课程、曲谱、调音或本机录音。关闭后 App 停止转发新的产品事件并调用 SDK 的统计关闭接口；不补传未同意期间的产品行为。已经发送的数据不因关闭开关自动删除，关闭也不等同于清除 SDK 内部已排队的数据；如需查询或删除，可通过本文支持邮箱以及友盟隐私政策中的渠道联系。

当前版本不集成广告、登录、支付或推送 SDK。

麦克风使用

吉他自习室会请求麦克风权限，用于在设备本地识别吉他的调音、单音和开放和弦练习结果；也用于你主动开启的“演奏留档”。

练习检测音频只在设备本地实时处理，不会保存，也不会包含在任何分析上报中。只有当你主动点击录音按钮时，App 才会把最长 180 秒的演奏录音保存到本机 Application Support 目录。当前版本也可在分段练习完成后主动录音，并将录音目录排除系统备份。App 不会自动上传录音，不会把录音用于广告、追踪或用户画像。

如果你拒绝麦克风权限，仍然可以查看课程、曲谱和和弦内容，但需要麦克风的检测和录音功能无法使用。当前版本还提供不需要麦克风的两分钟计时练习。可在系统设置中重新开启麦克风权限。

本机数据与删除

App 会在本机保存你的学习偏好、课程进度、练习记录、收藏、提醒设置，以及你主动创建的演奏录音。App 也会在本机保留最多 200 条近期产品事件缓存，部分基础功能事件即使统计关闭也只在本机保存；未同意期间的行为不会被补传。学习数据不与账号关联，App 不主动同步到开发者服务器；本机数据可能包含在用户自行开启的系统备份中，当前版本的录音目录除外。已启用统计时的事件和 SDK 数据按上节发送。

作品档案最多保留 24 条录音，超出容量时会淘汰较旧的普通作品。设为里程碑的录音不会自动淘汰，全部保留时需先取消保留或删除才能录制新作品。保存或中断异常遗留的未归档文件单独显示，可回放、导出后主动删除，不计作课程完成。你可以在“成长 > 演奏作品档案”中逐条删除；App 先确认保存引用变更，再清理被淘汰或手动删除的录音文件，存档失败时保留文件等待重试。删除 App 会删除该 App 容器中的学习数据和录音；已导出的副本和已有系统备份需要你在对应位置另行管理。

当你主动选择“导出演奏”时，系统分享面板会把选定音频及可选摘要交给你选择的应用或位置；接收方的数据处理由其服务规则决定。这个动作不会经过开发者服务器，取消分享也不会删除本机原件。当前版本的录音目录排除系统备份，重要作品请自行导出保存；课程进度、偏好和随机安装 ID 仍可能随你启用的系统备份恢复。

练习提醒与通知

练习提醒由你在“成长 > 练习设置 > 提醒与数据”中开启，并由系统请求通知权限。提醒时间和开关保存在本机，由设备安排本地通知，不使用远程推送服务。通知权限与麦克风权限、使用统计同意相互独立；关闭提醒会取消 App 已安排的待发送练习通知。只有你同意使用统计时，提醒开关及通知权限状态才会作为功能事件发送。

系统评分邀请

App 会根据本机的引导完成时间和练习记录判断是否适合请求系统评分，并在本机保存已请求的 App 版本号与请求时间，用于限制邀请频率。每个版本最多请求一次，两次请求至少间隔 120 天，滚动 365 天最多三次；是否显示由系统决定。上述邀请记录不会作为产品统计事件发送。

评分和评论由 Apple 按其 Apple 媒体服务条款处理。App 无法获知系统是否展示邀请或你是否提交评分，也不读取你的评分或评论内容。你可以忽略邀请，继续使用练习功能。

追踪

App 不包含广告，不主动读取 IDFA，不发起 ATT 请求，也不向数据经纪商出售数据。当前版本显式关闭 ASA / SKAN 广告归因及进端采集。友盟 SDK 的服务数据处理规则和完整收集范围请参阅其隐私政策；随机 ID 和设备标识并不等于完全匿名。

儿童隐私

当前版本面向一般吉他学习用户，不主动收集儿童个人信息。如果监护人认为孩子向我们提供了个人信息，请通过支持渠道联系删除。

数据安全

使用统计上传的数据包括上述功能事件、标识符及 SDK 自动处理的数据。本机学习档案和音频不会自动同步到开发者服务器；当前版本的主动导出由你决定接收方。主要隐私保护来自本机处理、App 沙盒和系统权限控制。请只在你信任的环境中授予麦克风权限，并妥善保护设备访问权限。

网站访问与支持邮件

营销、支持和隐私页面由 GitHub Pages 托管。本站未嵌入广告、访问统计脚本或追踪 Cookie。访问网页时，托管服务仍会接收提供页面所需的 IP 地址、浏览器及请求信息；其处理方式见 GitHub 隐私声明。打开 App Store 或友盟等外部链接后，适用对应服务的政策。

你主动发送支持邮件时，邮件服务会处理发件地址、邮件正文及你选择的附件；我们用这些信息回复问题或处理隐私请求。请只提供排查所需信息，不要发送密码、身份证件或不必要的个人录音。如需查询、更正或删除你提交的支持信息，请联系同一邮箱并说明请求范围。
