吉他自习室隐私政策

生效日期：2026-09-08

页面更新：2026-10-02

吉他自习室由 Shanghai Qishan Cultural Communication Co., Ltd. 提供。App 不需要注册账号，不包含广告，不会自动把你的练习录音上传到开发者服务器。

版本适用范围：2026-10-02 核对的 App Store 中国区公开版本仍为 1.2；1.3 / Build 8 为待发布版本。本页说明共同的数据处理方式，并单独标明 1.3 新增的选择和作品功能。1.2 已集成友盟统计并在启动后进行功能统计；下文“默认关闭、主动同意后初始化、随时关闭”的机制适用于 1.3，从你实际安装该版本起适用，不表示在架 1.2 已获得这些改动。

数据处理摘要

  • 练习检测音频：只在设备本地实时分析，不保存，不上传。
  • 主动演奏留档：最长 180 秒，档案最多保留 24 条，可逐条删除；1.3 支持里程碑保护、用户主动导出及未归档文件恢复。App 不自动上传。
  • 课程进度与设置：保存在 App 本机容器，可随你启用的系统备份迁移；开发者不提供云同步。
  • 使用分析：通过友盟统计 SDK 处理功能事件、随机安装 ID，以及 SDK 自动处理的设备标识和设备/网络信息。1.3 默认关闭，主动同意后才初始化统计 SDK。随机 ID 是假名化标识，不等同于不可识别个人的完全匿名数据。
  • 账号与广告：不需要账号，不包含广告；App 不主动读取 IDFA，不发起 ATT 授权请求。

我们收集的数据

本 App 不自动上传练习录音或音频内容；1.3 的主动导出由你选择接收应用或位置。使用统计中的设备标识和网络信息可能用于区分设备或安装，因此不将其描述为“完全匿名”。

App 不要求你提供姓名、手机号、邮箱、位置、通讯录、照片或社交账号。

我们使用友盟分析功能使用情况和改进产品。1.3 仅在你主动开启“分享使用统计”后初始化 SDK、转发产品事件；麦克风授权不代表统计同意。使用分析包括：

  • 产品交互数据：功能事件名与非个人化参数，例如「开始了某节课程」「完成了某类练习」「切换了某个标签页」。1.3 还包含练习开始/结果、主动计时时长、曲目与片段固定编号、作品保存/对比、周目标和系统分享结果；使用随机事件/会话/观察期编号去重，并记录发生时间、时区及版本。上述产品交互数据不包含你的录音、文件路径、音频特征或任何自由输入的文本；事件会附带随机安装标识符，因此不将它描述为“未关联标识符”的数据。
  • 随机安装标识符：App 首次启动时在本机随机生成的 ID，用于区分不同安装。该 ID 不与账号、手机号或真实身份关联；系统备份恢复可能恢复该安装 ID，不能保证每次重新安装都会变化。
  • SDK 设备与网络信息：友盟还会自动处理设备标识（如 IDFV/SDK 生成标识）、设备型号、操作系统与应用版本、语言、时区、网络状态及请求 IP 等信息。我们不将其收集范围简化为仅有 App 自定义事件。详细范围见友盟隐私政策。

第三方 SDK

App 集成友盟统计 SDK（UMCommon、UMDevice），由友盟同欣（北京）科技有限公司提供，用于上述产品统计。1.3 在取得统计同意后才初始化 SDK，并在初始化前显式关闭 ASA token 采集、SKAdNetwork 广告归因注册及进端采集。你可在“成长 > 练习设置”关闭“分享使用统计”。关闭后 App 停止转发新的产品事件并调用 SDK 的统计关闭接口；不补传未同意期间的产品行为。已经发送的数据不因关闭开关自动删除，关闭也不等同于清除 SDK 内部已排队的数据；如需查询或删除，可通过本文支持邮箱以及友盟隐私政策中的渠道联系。

当前版本不集成广告、登录、支付或推送 SDK。

麦克风使用

吉他自习室会请求麦克风权限，用于在设备本地识别吉他的调音、单音和开放和弦练习结果；也用于你主动开启的“演奏留档”。

练习检测音频只在设备本地实时处理，不会保存，也不会包含在任何分析上报中。只有当你主动点击录音按钮时，App 才会把最长 180 秒的演奏录音保存到本机 Application Support 目录。1.3 也可在分段练习完成后主动录音，并将录音目录排除系统备份。App 不会自动上传录音，不会把录音用于广告、追踪或用户画像。

如果你拒绝麦克风权限，仍然可以查看课程、曲谱和和弦内容，但需要麦克风的检测和录音功能无法使用。1.3 还提供不需要麦克风的两分钟计时练习。可在系统设置中重新开启麦克风权限。

本机数据与删除

App 会在本机保存你的学习偏好、课程进度、练习记录、收藏、提醒设置，以及你主动创建的演奏录音。学习数据不与账号关联，App 不主动同步到开发者服务器；本机数据可能包含在用户自行开启的系统备份中，1.3 的录音目录除外。已启用统计时的事件和 SDK 数据按上节发送。

作品档案最多保留 24 条录音，超出容量时会淘汰较旧的普通作品。1.3 中设为里程碑的录音不会自动淘汰，全部保留时需先取消保留或删除才能录制新作品。保存或中断异常遗留的未归档文件单独显示，可回放、导出后主动删除，不计作课程完成。你可以在“成长 > 演奏作品档案”中逐条删除；1.3 先确认保存引用变更，再清理被淘汰或手动删除的录音文件，存档失败时保留文件等待重试。删除 App 会删除该 App 容器中的学习数据和录音；已导出的副本和已有系统备份需要你在对应位置另行管理。

1.3 中，当你主动选择“导出演奏”时，系统分享面板会把选定音频及可选摘要交给你选择的应用或位置；接收方的数据处理由其服务规则决定。这个动作不会经过开发者服务器，取消分享也不会删除本机原件。1.3 的录音目录排除系统备份，重要作品请自行导出保存；课程进度、偏好和随机安装 ID 仍可能随你启用的系统备份恢复。

追踪

App 不包含广告，不主动读取 IDFA，不发起 ATT 请求，也不向数据经纪商出售数据。1.3 显式关闭 ASA / SKAN 广告归因及进端采集。友盟 SDK 的服务数据处理规则和完整收集范围请参阅其隐私政策；随机 ID 和设备标识并不等于完全匿名。

儿童隐私

当前版本面向一般吉他学习用户，不主动收集儿童个人信息。如果监护人认为孩子向我们提供了个人信息，请通过支持渠道联系删除。

数据安全

使用统计上传的数据包括上述功能事件、标识符及 SDK 自动处理的数据。本机学习档案和音频不会自动同步到开发者服务器；1.3 的主动导出由你决定接收方。主要隐私保护来自本机处理、App 沙盒和系统权限控制。请只在你信任的环境中授予麦克风权限，并妥善保护设备访问权限。

政策更新

如果未来版本增加账号、云同步、订阅或其他数据处理能力，本隐私政策会在发布前更新，并在 App Store Connect 中同步披露。
